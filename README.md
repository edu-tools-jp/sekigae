# 席替えアプリ

名簿を入れて、条件つきで席替えができるブラウザアプリです。インストールも会員登録も不要です。

**👉 https://edu-tools-jp.github.io/sekigae/**

## できること

- **名簿の読み込み**：出席番号・氏名・ふりがな・性別を並べたExcelファイル（.xlsx）を読み込みます。テキストの貼り付けにも対応。
- **条件つきの自動配置**：「この2人は離す」「この子は前から何行目まで」「この席に固定」などを指定できます。
- **ルーレット演出**：一人ずつ／一括のルーレットで、盛り上げながら決められます。
- **全画面表示と「確定」**：決まった座席を全画面で見せて、そのまま確定できます。確定後に解除して調整し直すこともできます。
- **教師視点／生徒視点**の向きを切り替えられます。
- **班の色分け・男女の色分け**。
- **印刷・JPG保存**：デザインは「シンプル／机（モダン）／机（木目）／シック」の4種類。
- **履歴**：過去の座席表を見返したり、復元したりできます。
- **複数のクラス・教室**を切り替えて使えます。
- **更新のお知らせ**：新しいバージョンが公開されると、画面右上の「更新」ボタンの色が変わります。更新内容を読んでから更新できます。

## データの保存について

名簿や座席表は、**使っているブラウザの中だけ**に保存されます。サーバーには送信しません。

- 別のパソコンで使うときは「ファイルに書き出す」で保存し、移した先で「バックアップから復元」してください。
- ブラウザの閲覧履歴データ（サイトデータ）を消すと、名簿も消えます。

このアプリがインターネットに出るのは、**新しいバージョンが出ていないかを確認するとき（`version.json` を読むだけ）** と、**更新のファイルをダウンロードするとき**だけです。名簿などのデータが外に出ることはありません。更新の確認は「設定」タブでオフにできます。

## アプリの更新

新しいバージョンを公開すると、アプリを開いたときに自動で気づけるようになっています。

1. 画面右上の「🔄 更新」ボタンが、**オレンジ色の「🆕 更新があります」**に変わります
2. 押すと、**何が変わったか（更新内容）**が一覧で表示されます
3. そのまま更新できます

**サイト（上のURL）から使っている場合**
「更新する」を押すと、その場で最新版を読み込み直します。数秒で終わります。

**`index.html` をパソコンに置いて使っている場合（オフライン版）**
「新しいファイルをダウンロード」を押すと、最新の `index.html` が保存されます。いま使っているファイルと置き換えて、新しいほうを開いてください。

- **名簿・座席・履歴などのデータは、ファイルではなくブラウザの中に保存されています。** ファイルを置き換えても、これまでのデータはそのまま使えます（念のため、先にバックアップを保存しておくと安心です）。
- 古いファイルを開くと古い画面が出ます。置き換えたら古いファイルは削除してください。

そのため、**他の先生に配った後も、更新版のファイルを送り直す必要はありません。** それぞれのパソコンで「更新があります」と表示され、その場で最新版に差し替えられます。

更新の確認は「設定」タブの「アプリの更新」からいつでも手動でできます。自動の確認をオフにすることもできます（オフにしても、これまでどおりオフラインで使えます）。

## 動作環境

Google Chrome / Microsoft Edge（最新版）を想定しています。

必要な部品をすべて1つのファイルに入れてあるので、**一度開けばネットが無くても動きます**。`index.html` をダウンロードして、パソコンに置いて使うこともできます。
